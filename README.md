## The entry

> I told my smart speaker I feel lonely. It said, 'I'm sorry, I didn't quite catch that.'

## How it works

`main.py` (Python standard library only) writes that single original one-liner to the output path — `/output/entry.txt` by default, or the path named by `ENTRY_OUT` / `ENTRY_OUT_DIR` / `OUTPUT` when set (a directory value means `<dir>/entry.txt`). No trailing newline, so the file holds exactly the joke: 87 characters, inside the 1–140 character gate.

## Run it

```sh
python3 main.py
```
